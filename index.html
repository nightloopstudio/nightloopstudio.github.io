Privacy Policy — Nightloop Studio

Last updated: 29 July 2026

Nightloop Studio operates a set of original music and artwork channels. This policy explains how our Pinterest application handles data.

What the application does

Our application publishes Pins of artwork we created ourselves to our own Pinterest account. Each Pin links to the corresponding video on our own YouTube channels. Posting runs on an automated daily schedule.

Data we collect from Pinterest users

None. The application does not access, collect, store, share, or process personal data belonging to any Pinterest user. It has no user-facing interface, no sign-in, and no other users. It operates solely on the Pinterest account owned by Nightloop Studio.

Data we store

We store only the credentials required to publish to our own account (an application ID, secret, and OAuth access token), together with a record of which of our own images have already been posted so that we do not post duplicates. These are held privately on our own server and are never shared with any third party.

Third-party services

The application communicates with the Pinterest API to publish Pins. Pins link to publicly available YouTube videos. We do not use advertising networks, analytics services, or trackers of any kind.

Data retention and deletion

Because we collect no user data, there is no user data to retain or delete. Our own stored credentials are removed if the application is discontinued.

Children's privacy

The application is not directed at children and collects no data from anyone, including children.

Changes to this policy

Any updates will be posted on this page with a revised date above.
